The goal of this assignment is to help you understand how Docker functions, and basic networking

To run, open this directory in your terminal and run "docker compose up". Then in another terminal, with the directory open, run "curl localhost:8080". You should get the message you put in "hello.js"

Please refer to these sources to learn about the functioning of this system.
